# Anime Data Analysis

## Overview

This project analyzes an anime dataset using Python and Pandas in Jupyter Notebook.

## Tasks Performed

* Created a new column for episode count.
* Created a new column for timestamp/duration.
* Found the anime with the highest score.
* Identified the top 5 highest-scoring anime.
* Found the anime with the highest episode count.
* Identified the top 5 anime with the highest episode counts.
* Determined the longest-running anime.

## Tools Used

* Python
* Pandas
* Jupyter Notebook

## Learning Outcomes

* Data cleaning and preprocessing
* Creating new columns
* Sorting and filtering data
* Basic data analysis with Pandas
